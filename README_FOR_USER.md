# 동영상 받기 프로그램 — 쉬운 설명

이 프로그램은 **동영상 주소**를 넣으면 **내 컴퓨터에 동영상 파일로 저장**해 줍니다.  
따로 뭘 깔아야 하지는 않습니다.

## 어디서 쓰나요?

Windows 컴퓨터에서 씁니다.

## 처음 켤 때

창이 뜨면 **추가 정보** 또는 **자세히**를 누른 다음 **실행**을 누릅니다.  
회사에서 준 건지 먼저 확인하세요.

## 순서대로 하기

1. 프로그램을 켭니다.
2. **주소 칸**에 받을 **동영상 주소**를 붙여 넣습니다. (보통 인터넷 주소처럼 `http` 로 시작해요.)
3. **찾아보기**로 **저장할 폴더**만 고릅니다. (이름은 프로그램이 알아서 정해 줘요.)
4. **다운로드**를 누릅니다. 끝나면 글씨로 알려 줍니다.
5. **저장 폴더 열기**를 누르면 저장된 곳이 열려요.

멈추고 싶으면 **중지**를 누르세요.

## 안 될 때

인터넷이 잘 되는지, 주소가 맞는지 봅니다.  
그래도 안 되면 화면 사진을 찍어서 선생님이나 회사 도움 받는 사람에게 보여 주세요.

**복사가 막혀 있는 영화 같은 건** 이 프로그램으로는 못 받을 수 있어요.
